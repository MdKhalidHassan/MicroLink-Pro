# 🎙️ MicroLink Pro

**MicroLink Pro** হলো উবুন্টু (Ubuntu) ও ডেবিয়ান (Debian) লিনাক্স ব্যবহারকারীদের জন্য একটি হালকা ও আধুনিক পাইথন অ্যাপ্লিকেশন। এটি আপনার অ্যান্ড্রয়েড স্মার্টফোনের শারীরিক মাইক্রোফোনকে কোনো প্রকার অডিও লেটেন্সি (Audio Delay) বা জটিল সেটিংস ছাড়াই সরাসরি লিনাক্স পিসির প্রধান সিস্টেমে মাইক্রোফোন (Default Microphone) হিসেবে যুক্ত করে।

আপনার অতিরিক্ত কোনো থার্ড-পার্টি অ্যান্ড্রয়েড অ্যাপ ইনস্টল করার প্রয়োজন নেই। কেবল `scrcpy` এবং লিনাক্সের `PulseAudio/PipeWire` ড্রাইভার ব্যবহার করেই এই অ্যাপ্লিকেশনটি নিখুঁতভাবে কাজ করে।

## 🔌 প্রয়োজনীয় জিনিসপত্র (Requirements)

- **হার্ডওয়্যার:** 
  - একটি অ্যান্ড্রয়েড স্মার্টফোন।
  - একটি ভালো মানের USB ডাটা ক্যাবল (যা দিয়ে ফাইল ট্রান্সফার করা যায়)।
  - একটি লিনাক্স পিসি (Ubuntu 20.04+, Debian 11+, Linux Mint, Pop!_OS ইত্যাদি)।
- **সফটওয়্যার:** Python 3, Tkinter, Scrcpy, এবং PulseAudio Utilities।

## 📱 ধাপ ১: ফোনে ডেভেলপার অপশন ও USB Debugging চালুকরণ

অ্যান্ড্রয়েড ফোনকে পিসির সাথে ক্যাবলের মাধ্যমে সরাসরি ডেটা আদান-প্রদান করতে দিতে **USB Debugging** ফিচারটি অন করতে হয়। নিচের নিয়ম অনুসরণ করুন:

1. **Developer Options অন করা:**
   - ফোনের **Settings** এ যান।
   - নিচে স্ক্রোল করে **About Phone** (বা **About Device**) এ ঢুকুন।
   - **Software Information** অপশনে যান (কিছু ফোনে সরাসরি বাইরেই থাকে)।
   - **Build Number** লেখাটি খুঁজে বের করুন এবং এর ওপর পরপর **৭ বার (7 times)** ট্যাপ বা ক্লিক করুন।
   - স্ক্রিনে দেখতে পাবেন: *"You are now a developer!"* বা আপনার ফোনের লক স্ক্রিনের পিন/প্যাটার্ন দিয়ে কনফার্ম করতে বলবে।

2. **USB Debugging অন করা:**
   - আবার ফোনের প্রধান **Settings**-এ ফিরে যান।
   - একদম নিচে নতুন একটি অপশন দেখতে পাবেন: **Developer Options**। এটিতে ক্লিক করুন।
   - নিচের দিকে স্ক্রোল করে **Debugging** সেকশনের অধীনে **USB Debugging** অপশনটি খুঁজে বের করে **ON** করে দিন।

3. **পিসির সাথে ফোনের সংযোগ ও পারমিশন দেওয়া:**
   - এবার USB ক্যাবল দিয়ে ফোনটি লিনাক্স পিসির সাথে যুক্ত করুন।
   - ফোনের স্ক্রিনে একটি পপ-আপ মেসেজ আসবে: *"Allow USB debugging?"*
   - **"Always allow from this computer"** বক্সে টিক চিহ্ন দিন এবং **Allow** বা **OK** সিলেক্ট করুন।
