# 🎙️ MicroLink Pro

**MicroLink Pro** হলো উবুন্টু (Ubuntu), ডেবিয়ান (Debian) এবং লিনাক্স মিন্ট (Linux Mint) ব্যবহারকারীদের জন্য তৈরি একটি সহজ ও প্রফেশনাল পাইথন অ্যাপ্লিকেশন। এটি আপনার অ্যান্ড্রয়েড ফোনের আসল মাইক্রোফোনকে কোনো প্রকার অডিও ল্যাগ বা ঝামেলা ছাড়াই লিনাক্স পিসির প্রধান সিস্টেম মাইক্রোফোন (Default Microphone) হিসেবে যুক্ত করে।

অ্যান্ড্রয়েড ফোনে অতিরিক্ত কোনো থার্ড-পার্টি অ্যাপ ইনস্টল করতে হয় না। কেবল USB ক্যাবল এবং লিনাক্সের বিল্ট-ইন ড্রাইভার ও `scrcpy` ব্যবহার করেই এটি কাজ করে।

## 🔌 প্রয়োজনীয় জিনিসপত্র (Prerequisites)

- **অ্যান্ড্রয়েড ফোন:** যেকোনো অ্যান্ড্রয়েড স্মার্টফোন।
- **USB ক্যাবল:** একটি ভালো মানের ডাটা ক্যাবল (যা দিয়ে ফাইল ট্রান্সফার করা যায়)।
- **অপারেটিং সিস্টেম:** Ubuntu 20.04+, Debian 11+, Linux Mint, Pop!_OS বা যেকোনো Debian-based লিনাক্স।

## 📱 ধাপ ১: ফোনে ডেভেলপার অপশন ও USB Debugging চালু করা

পিসির সাথে ফোনের মাইক্রোফোন কানেক্ট করার জন্য ফোনে **USB Debugging** অপশনটি অন থাকতে হবে।

1. **ডেভেলপার অপশন অন করুন:**
   - ফোনের **Settings** এ যান।
   - একদম নিচে গিয়ে **About Phone** (বা **About Device**) সিলেক্ট করুন।
   - **Software Information** এ যান (কিছু ফোনে সরাসরি বাইরে থাকে)।
   - **Build Number** অপশনটির ওপর পরপর **৭ বার (7 times)** দ্রুত ট্যাপ করুন।
   - স্ক্রিনে দেখতে পাবেন: *"You are now a developer!"* লেখা উঠেছে।

2. **USB Debugging চালু করুন:**
   - ফোনের প্রধান **Settings** মেনুতে ফিরে আসুন।
   - একদম নিচে দেখুন নতুন একটি অপশন এসেছে: **Developer Options**। এটিতে ক্লিক করুন।
   - স্ক্রোল করে **Debugging** সেকশনে যান এবং **USB Debugging** এর পাশের সুইচটি **ON** করে দিন।

3. **পিসিতে কানেক্ট ও পারমিশন দেওয়া:**
   - USB ক্যাবল দিয়ে ফোনটি পিসির সাথে প্লাগ-ইন করুন।
   - ফোনের স্ক্রিনে একটি পপ-আপ আসবে: *"Allow USB debugging?"*
   - **"Always allow from this computer"** বক্সে টিক দিয়ে **Allow** বা **OK** বাটনে চাপুন।

## 🚀 ধাপ ২: সফটওয়্যার ইনস্টল ও চালনা (৩টি সহজ পদ্ধতি)

আপনার সুবিধামত যেকোনো একটি পদ্ধতি অনুসরণ করে অ্যাপটি সেটআপ করুন:

---

### পদ্ধতি ১: .deb প্যাকেজ দিয়ে ইনস্টল (সবচেয়ে সহজ)

আপনি যদি টার্মিনালে বেশি কমান্ড না লিখে সাধারণ সফটওয়্যারের মতো ইনস্টল করতে চান:

১. **Releases** সেকশন থেকে `microlink-pro.deb` ফাইলটি ডাউনলোড করুন।  
২. ডাউনলোডের পর ফাইলটির ওপর **ডাবল-ক্লিক** করুন। উবুন্টু **Software Center** ওপেন হবে।  
৩. **Install** বাটনে ক্লিক করুন এবং পিসির পাসওয়ার্ড দিন।  
৪. ইনস্টল শেষ হলে আপনার লিনাক্সের **App Launcher / Show Applications** মেনুতে গিয়ে **"MicroLink Pro"** লিখে সার্চ দিলেই অ্যাপটি পেয়ে যাবেন!

*(অথবা টার্মিনালে এই একটি লাইন দিলেও `.deb` ইনস্টল হয়ে যাবে: `sudo apt install ./microlink-pro.deb`)*

---

### পদ্ধতি ২: ডাবল-ক্লিক এক্সিকিউটেবল / শর্টকাট আইকন দিয়ে রান

আপনি যদি ইনস্টল না করে সরাসরি বাইনারি ফাইল বা ডেস্কটপ আইকনে ক্লিক করে চালাতে চান:

১. প্রজেক্টের রিলিজ ফোল্ডার থেকে `MicroLink-Pro.desktop` বা এক্সিকিউটেবল রানার ফাইলটি নামিয়ে নিন।  
২. ফাইলটির ওপর মাউসের রাইট-ক্লিক (Right-Click) করে **Properties > Permissions** এ যান।  
৩. **"Allow executing file as program"** অপশনে টিক চিহ্ন দিন।  
৪. এবার ফাইলটির ওপর রাইট ক্লিক করে **"Allow Launching"** দিন।  
৫. এখন সরাসরি ফাইলটিতে **ডাবল-ক্লিক (Double Click)** করলেই সফটওয়্যারটির GUI ইন্টারফেস চালু হয়ে যাবে!
